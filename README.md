# Camila Run — protótipo Web

Jogo de parkour 2D em HTML, CSS e JavaScript puro com Canvas. Não precisa instalar dependências.

## Executar no GitHub Codespaces
No terminal, rode:

```bash
python3 -m http.server 8000
```

Abra a aba **Ports**, localize a porta **8000** e clique em **Open in Browser**.

## Controles
- Espaço ou seta para cima: saltar
- Seta para baixo: deslizar
- Celular: botões na tela

## Estado
Versão inicial jogável (v0.1), com avatares estilizados provisórios, corrida, obstáculos, perseguição, pontuação e recorde local. Os visuais não são retratos oficiais nem sprites finais.

## Próximas melhorias
Sprites quadro a quadro, fases, novos obstáculos, efeitos sonoros e adaptação para aplicativo Android com Capacitor.
